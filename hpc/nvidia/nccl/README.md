NVIDIA NCCL (NVIDIA Collective Communication Library)
=====================================================

NCCL provides the following collective communication primitives:

- AllReduce
- Broadcast
- Reduce
- AllGather
- ReduceScatter
- AlltoAll
- Gather
- Scatter

See [draw](../../mpi/README.md).


Support **PCIe**, **NVLinks**, **InfiniBand Verbs**, **IP Sockets**.
