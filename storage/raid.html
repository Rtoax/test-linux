RAID - Redundant Arrays of Independent Disks

RAID 0

 RAID0(Linear)       RAID0(Striped)
  +--------+           +--------+
  |        |           |        |
+-+--+  +--+-+       +-+--+  +--+-+
| A1 |  | A2 |       | A1 |  | A4 |
+----+  +----+       +----+  +----+
| A3 |  | A4 |       | A2 |  | A5 |
+----+  +----+       +----+  +----+
| A5 |  | A6 |       | A3 |  | A6 |
+----+  +----+       +----+  +----+
Disk1    Disk2       Disk1   Disk2

RAID 1

    RAID 1
  +--------+
  |        |
+-+--+  +--+-+
| A1 |  | A1 |
+----+  +----+
| A2 |  | A2 |
+----+  +----+
| A3 |  | A3 |
+----+  +----+
Disk1   Disk2

RAID 10

            RAID 10
             RAID 0
      +-----------------+
      |                 |
    RAID 1            RAID 1
  +--------+        +--------+
  |        |        |        |
+-+--+  +--+-+    +-+--+  +--+-+
| A1 |  | A1 |    | A2 |  | A2 |
+----+  +----+    +----+  +----+
| A3 |  | A3 |    | A4 |  | A4 |
+----+  +----+    +----+  +----+
| A5 |  | A5 |    | A6 |  | A6 |
+----+  +----+    +----+  +----+
Disk1    Disk2    Disk3   Disk4

RAID 2

  • 很少用到;

RAID 3

           RAID 3
  +--------+-------+--------+
  |        |       |        |
+-+--+  +--+-+  +--+-+  +---+----+
| A1 |  | A2 |  | A3 |  | Ap(123)|
+----+  +----+  +----+  +--------+
| A4 |  | A5 |  | A6 |  | Ap(456)|
+----+  +----+  +----+  +--------+
| B1 |  | B2 |  | B3 |  | Bp(123)|
+----+  +----+  +----+  +--------+
| B4 |  | B5 |  | B6 |  | Bp(456)|
+----+  +----+  +----+  +--------+
Disk1   Disk2   Disk3     Disk4

  • Disk4 用于存放校验码，有损坏可以及时恢复；

  • Disk4 频繁写入容易损坏；

RAID 5

           RAID 5
   +------+-------+-------+
   |      |       |       |
+--+-+  +-+--+  +-+--+  +-+--+
| A1 |  | A2 |  | A3 |  | Ap |
+----+  +----+  +----+  +----+
| B1 |  | B2 |  | Bp |  | B3 |
+----+  +----+  +----+  +----+
| C1 |  | Cp |  | C2 |  | C3 |
+----+  +----+  +----+  +----+
| Dp |  | D1 |  | D2 |  | D3 |
+----+  +----+  +----+  +----+
Disk1   Disk2   Disk3   Disk4

  • RAID5 至少 3 块盘;

  • 解决 RAID4 校验码磁盘频繁写入，容易损坏的问题;
