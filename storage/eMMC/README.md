eMMC - embedded Multi-MediaCard
===============================

嵌入式多媒体卡,是一种闪存卡的标准，它定义了基于嵌入式多媒体卡的存储系统的物理架
构和访问接口及协议，具体由电子设备工程联合委员会JEDEC订立和发布。它是对MMC的一
个拓展，具有体积小，功耗低，容量大等优点，非常适合用作智能手机、平板电脑、移动
互联网设备等消费类电子设备的存储介质。


# 关键词

- GPP: General Purpose Partitions
- RPMB: Replay Protected Memory Block (Partition)
- UDA: User Data Area (Partition)
