Interrupt

# IRQ assignments

```
IRQ	Device
--------------------
0	System timer
1	Keyboard (PS/2)
2	Cascade from IRQ 9
8	Real-time clock (RTC)
12	Mouse (PS/2)
```


# x86

* cli - Clear Interrupt flag: Clear IF(Interrupt flag) disable interrupt
* sti - Set Interrupt flag: Set IF(Interrupt flag) enable interrupt
