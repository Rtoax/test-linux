==========================
UAPI (Linux Userspace API)
==========================

The Linux Userspace API (UAPI) Group
------------------------------------

The userspace API (“uapi”) group is a community for people with an interest in
innovating how we build, deploy, run, and securely update modern Linux operating
systems. It serves as a central gathering place for specs, documentation, and
ideas.
