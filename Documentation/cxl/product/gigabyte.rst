Gigabyte CXL
============

R284-A91-AAL3
-------------

Rack Server - Intel® Xeon® 6900E+/6900-Series Processors - 2U DP 4-Bay E3.S Gen5 NVMe + 16-Bay E3.S 2T `CXL`.

* Dual Intel® Xeon® 6900E+/6900-Series Processors
* 12-Channel DDR5 RDIMM/MRDIMM per CPU with 24 x DIMMs
* 2 x 1 Gb/s LAN ports via Intel® I350-AM2
* 4 x E3.S Gen5 NVMe hot-swap bays
* 16 x E3.S 2T bays for `CXL` memory expansion modules
* 2 x 2.5" SATA/SAS-4 hot-swap bays on the rear side
* 2 x M.2 slots with PCIe Gen5 x4
* 1 x FHHL PCIe x16 slot with Gen5 x16 lanes
* 1 x OCP NIC 3.0 PCIe Gen5 x16 slot
* 1+1 2700 W 80 PLUS Titanium redundant power supplies
