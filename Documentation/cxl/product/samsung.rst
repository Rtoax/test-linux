Samsung CXL
===========

Samsung CXL Memory Module (CMM)
-------------------------------

.. list-table::
   :header-rows: 1

   * - Module
     - Note
   * - CMM-D
     - 用于扩展内存，强调高性能和低延迟。
   * - CMM-H (Hierarchy)
     - 支持分层内存解决方案，具有更复杂的数据路径（.mem和.io）。
   * - CMM-HC (Hybrid with Compute)
     - 集成加速器的设计，支持多种数据路径（.cache、.mem和.io），适用于高性能计算应用。
