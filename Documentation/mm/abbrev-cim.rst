Abbrev Computing In Memory (CIM)
================================

- CAM: Content Addressable Memory (内容寻址存储器)
- CIM: Computing In Memory (存内计算,存算一体,处理in内存) @CNM @PIM
- CNM: Compute Near Memory (近内存计算) @CIM
- C-RAM: Computational RAM (计算 RAM) @PIM
- IMC: Computing with memory or in-memory computing (使用内存计算)
- IRAM: Intelligent RAM (智能 RAM)
- PIM: Processing In Memory (存内处理) @CIM @PuM @PnM @C-RAM
- PnM: Processing-near-memory (近内存处理) @PIM
- PuM: Processing-using-memory (使用存储器的处理) @PIM
- V-IRAM: Vector IRAM (向量 IRAM) @V-IRAM
