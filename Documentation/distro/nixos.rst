NixOS
=====

NixOS is a Linux distribution built around the Nix package manager. Unlike
traditional Linux distributions, NixOS is configured using a functional
language that describes the system configuration. It generates complete system
profiles, enabling reproducible deployments, atomic upgrades, and system
rollbacks.


Nix
---

Nix is a powerful package manager for Linux and other Unix systems that makes
package management reliable and reproducible. Please refer to the Nix manual
for more details.
