Abbrev

  • BLAS: Basic Linear Algebra Subprograms (基本线性代数子程序)

  • BO: Buffer Object (缓冲目标)

  • CSC: Compressed Sparse Column (压缩稀疏列) @CSR

  • CSR: Compressed Sparse Row (压缩稀疏行) @CSC

  • CUDA: Compute Unified Device Architecture (计算统一设备架构)

  • DP: Double Precision (双精度) @FP64

  • FLOPs: Floating Point of Operations (浮点运算)

  • FLOPS: Floating Point Operations Per Second (每秒浮点运算个数)

  • FMA: Fused Multiply-Add (a x b + c)

  • FP64: FP 64-bit (双精度浮点) @DP

  • FP: Float Point (浮点, IEEE 754-2008) @TF

  • GART: Graphics Address Remapping Table (图形地址重映射表)

  • GDS: GPUDirect Storage (GPUDirect存储)

  • GEM: Graphics Execution Manager (图形执行管理器)

  • GEMM: General Matrix-Matrix Multiplication (广义矩阵乘法, C=α⋅A⋅B+β⋅C)

  • GEMV: Generalized Matrix-Vector Multiplication (广义矩阵向量乘法, y=α⋅A⋅x+β⋅y)

  • GFLOPS: Giga FLOPS (每秒10亿次的浮点运算数) @FLOPS

  • GMC: GFX Memory Controller (GFX内存控制器)

  • GPC: Graphics Processing Cluster (图形处理器集合)

  • GPU: Graphics Processing Unit (图形处理器)

  • HBM2E: HBM2E ()

  • HBM2: HBM 2 generation (第二代 HBM) @HBM

  • HBM: High Bandwidth Memory (高带宽内存)

  • HCC: HPC Cluster (高性能计算集群)

  • HC: Heterogeneous Computing (异构计算)

  • HIP: C++ Heterogeneous-Compute Interface for Portability (C++异构计算接口的可移植性)

  • HPC: High Performance Compute (高性能计算)

  • MFLOPS: Mega FLOPS (每秒一百万次的浮点运算)

  • OAI: Open Accelerator Infrastructure (开放加速器基础设施) @OCP

  • OAM: Open Accelerator Module (开放加速器模组) @OCP

  • OCP: Open Compute Project (开放计算项目)

  • OpenCL: Open Computing Language (开放计算语言)

  • OPS: Operations Per Second (每秒操作数)

  • PSP: Platform Security Processor (平台安全处理器)

  • PTI: CUDA Profiling Tools Interface (剖析工具接口)

  • SASS: Streaming ASSembly (原生机器码指令集)

  • SFU: Special Function Unit (特定功能单元)

  • sGPU: Sliced GPU (GPU切片)

  • SMI: System Management Interface (系统管理接口, nvidia-smi)

  • SMP: SM Processing Block (SM 处理块) @SM

  • SM: Streaming Multiprocessors (流式多处理器) @SMP

  • SP: Streaming Processor (流式处理器, CUDA Core)

  • TFLOPS: teraFLOPS (每秒一万亿次的浮点运算)

  • TF: TensorFloat (张量浮点) @TF @FP

  • TOPS: Tera Operations Per Second (处理器每秒一万亿次)

  • TPC: Texture Processing Cluster (纹理处理器集群)

  • TTM: Translation Table Maps (翻译表映射)

  • VRAM: Video RAM (视频RAM)

  • WSM: Workgroup Shared Memory (工作组共享内存)
