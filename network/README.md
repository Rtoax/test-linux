# IPv4

Ranges for the five different classes of IPv4 addresses.

```
+------------+--------+-------------------------------+
|  usage     | class  |              range            |
+------------+--------+-------------------------------+
|Unicase     | A,B,C  |   0.0.0.0  ~ 223.255.255.255  |
|Multicase   |   D    |   224.0.0.0 ~ 239.255.255.255 |
|Experimental|   E    |   240.0.0.0 ~ 255.255.255.255 |
+------------+--------+-------------------------------+
```
