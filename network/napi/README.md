NAPI - New API
==============

新 API（也称为 NAPI）是一个接口，用于在 Linux 内核中为网络设备使用中断缓解技术。
这种方法旨在减少数据包接收的开销。这个想法是推迟传入消息的处理，直到有足够数量
的消息，这样才值得一次处理所有消息。

实现网络驱动程序的一种直接方法是通过为每个传入数据包发出中断请求 (IRQ) 来中断内
核。然而，服务 IRQ 在处理器资源和时间方面成本很高。因此，直接实现在高速网络中效
率非常低，每秒不断中断内核数以千计的数据包。系统的整体性能以及网络吞吐量可能因
此受到影响。

轮询是基于中断处理的替代方法。内核可以在不被中断的情况下定期检查传入网络数据包
的到达，从而消除了中断处理的开销。但是，建立最佳的轮询频率很重要。过于频繁的轮
询会反复检查尚未到达的传入数据包，从而浪费 CPU 资源。另一方面，轮询频率太低会
降低系统对传入数据包的反应性，从而引入延迟，如果传入数据包缓冲区在处理之前已满，
则可能会导致数据包丢失。

作为妥协，Linux 内核默认使用中断驱动模式，只有当传入数据包的流量超过某个阈值
（称为网络接口的“权重”）时才切换到轮询模式。
