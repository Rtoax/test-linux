SSE (Streaming SIMD Extensions)
===============================


# Headers

## SSE2


```c
extern "C"
{
    #include <emmintrin.h>
    #include <mmintrin.h>
}
```


## SSE3

```c
extern "C"
{
    #include <pmmintrin.h>
    #include <immintrin.h>   // (Meta-header)
}
```


## SSE4

```c
extern "C"
{
    #include <smmintrin.h>
}
```
