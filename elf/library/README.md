ELF Library
===========


# Dynamic Library

```
+------------+    +-----+    +-----+    +---------+
|main() {    |    |     |    |     |    |         |
|  foo@plt();|    | PLT |    | GOT |    | library |
|}           |    |     |    |     |    |         |
+------------+    +-----+    +-----+    +---------+
   call ----------> jmp ---> GOT[idx] ----> foo()
            [1]         [2]            [3]
```

# Static Library

```
+------------+                          +---------+
|main() {    |                          |  foo() {|
|  foo();    |                          |    ...  |
|}           |                          |  }      |
+------------+                          +---------+
   call ---------------------------------->
                         [4]
```
