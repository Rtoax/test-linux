Integrity Measurement Architecture (IMA)
=========================================


内核完整性子系统的目标是检测文件是否被远程和本地意外或恶意更改，根据存储为扩展属性的“良好”值评估文件的度量，并强制执行本地文件完整性。这些目标是对 LSM 模块（例如 SElinux 和 Smack）提供的强制访问控制 (MAC) 保护的补充，后者可以根据策略尝试保护文件完整性。以下模块提供几个完整性功能：

- Collect 收集- 在文件被访问之前对其进行测量。
- Store 存储- 将测量添加到内核驻留列表，如果存在硬件可信平台模块 (TPM)，则扩展 IMA PCR
- Attest - 如果存在，使用 TPM 对 IMA PCR 值进行签名，以允许对测量列表进行远程验证。
- Appraise 评估- 针对存储在文件扩展属性中的“良好”值强制执行测量的本地验证。
- Protect - 保护文件的安全扩展属性

前三个功能是在 2.6.30 中通过完整性测量架构 (IMA) 引入的。EVM/IMA 评估补丁添加了对最后两个功能的支持。
