Audit(审计)
===========

Audit 通过 netlink 与内核进行交互(`NETLINK_AUDIT`)。


# Architecture

```
        +-------------+      +-------------+       +--------------+
        | audit.rules |      | auditd.conf |       |    audispd   |
        +------+------+      +------+------+       +-^------------+
               |                    |                |
               |                    |                |
               |                    |                |               +------------+
        +------v------+      +------v------+         |          +---->  aureport  |
        |   auditctl  +------>   auditd    +---------+          |    +------------+
        +-----------+-+      +------^------+         |          |
                    |               |                |          |
                    |               |              +-v----------+-+  +------------+
+-------------+     |       +-------+              |   audit.log  +-->  ausearch  |
| Application |     |       |                      +--------------+  +------------+
+------+------+     |       |
       |            |       |
+------v-----------+v-------+------+            +--------------+
|                  |      audit    <------------+   autrace    |
    Kernel         +---------------+            +--------------+
|                                  |
+----------------------------------+
```
