PIC - 中断控制器
=================

PIC 中断控制器原理
------------------

.. code-block:: text

                    |       |
                    |       +--------------+
                    |       |              |
            +-------+-------+-------+      |
            |      INT    -INT      |      |
        ----+ IRQ0                  |      |
        ----+ IRQ1                  |      |
     +------+ Cascade to Slave      |      |
     |  ----+ IRQ3                  |      |
     |  ----+ IRQ4   8259 PIC       |      |
     |  ----+ IRQ5                  |      |
     |  ----+ IRQ6                  |      |
     |  ----+ IRQ7                  |      |
     |      |         Master        |      |
     |      +-----------------------+      |
     |                                     |
     |                                     |
     +--------------+       +--------------+
                    |       |
            +-------+-------+-------+
            |      INT    -INT      |
        ----+ IRQ8                  |
        ----+ IRQ9                  |
        ----+ IRQ10                 |
        ----+ IRQ11                 |
        ----+ IRQ12  8259 PIC       |
        ----+ IRQ13                 |
        ----+ IRQ14                 |
        ----+ IRQ15                 |
            |         Slave         |
            +-----------------------+


XT-PIC
------

XT-PIC 是最古老的中断分发方式，用于单处理器系统。

XT-PIC 中断模式使用两个 `Intel 8259` 中断控制芯片(又叫 `PIC` 芯片), 计算机系统能够支持 15 个中断。


PIC 8259A
---------

在80X86微机机系统中采用了8259A可编程中断控制器芯片.
