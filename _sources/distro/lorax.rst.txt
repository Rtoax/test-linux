Lorax
=====

You can see the lorax template from `lorax <https://github.com/weldr/lorax>`_ source code tree, or see `website <https://weldr.io/lorax/lorax.html>`_.


ISOLABEL
--------

LABEL size limit

- NTFS Drives: Maximum of 32 characters
- FAT Drives: Maximum of 11 characters

For example: modify `80-fedora/x86.tmpl` isolabel name.
