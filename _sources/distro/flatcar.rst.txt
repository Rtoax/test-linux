Flatcar
=======

Flatcar Container Linux is a container-optimized OS, with a minimal image size
including only the tools needed to run containers.

Flatcar based on Gentoo.

- `Flatcar Container Linux <https://www.flatcar-linux.org/docs/latest/>`_
- `Guide to building customised Flatcar images <https://www.flatcar-linux.org/docs/latest/reference/developer-guides/sdk-modifying-flatcar/>`_
