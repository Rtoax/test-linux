Anaconda
========

Basic
-----

- Switch TTY: `CRTL + ALT + F1~F7`


Add-ons
-------

- `Developing Installer Add-ons <https://access.redhat.com/documentation/en-us/red_hat_enterprise_linux/7/html/anaconda_customization_guide/sect-anaconda-addon-development#sect-writing-anaconda-addon>`_

Anaconda add-ons can be used to add your own Kickstart commands and options as well as new configuration screens in the graphical and text-based user interface, depending on your specific use case.

- add-on hello: `rhinstaller/hello-world-anaconda-addon <https://github.com/rhinstaller/hello-world-anaconda-addon>`_
