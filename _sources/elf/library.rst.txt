ELF Library
===========


Dynamic Library
---------------

.. code-block:: text

  +------------+    +-----+    +-----+    +---------+
  |main() {    |    |     |    |     |    |         |
  |  foo@plt();|    | PLT |    | GOT |    | library |
  |}           |    |     |    |     |    |         |
  +------------+    +-----+    +-----+    +---------+
     call ----------> jmp ---> GOT[idx] ----> foo()
              [1]         [2]            [3]


Static Library
--------------

.. code-block:: text

  +------------+                          +---------+
  |main() {    |                          |  foo() {|
  |  foo();    |                          |    ...  |
  |}           |                          |  }      |
  +------------+                          +---------+
     call ---------------------------------->
                           [4]
