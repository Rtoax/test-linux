Abbrev NVMe
===========

- L2P Table: LBA to PBA Table (逻辑与物理地址映射关系表) @LBA @PBA
- LBA: Logical Block Addresses (逻辑块地址) @PBA
- PBA: Physical Block Address (物理块地址) @LBA
- NCAP: Namespace Capacity (命名空间容量)
- NSID: Namespace ID (命名空间 ID)
- NSZE: Namespace Size (命名空间大小)
- NUSE: Namespace Utilization (命名空间利用率)
- NVM: Non-Volatile Memory (非易失性内存)
- NVMe: Non-Volatile Memory Express (非易失性内存表达)
- NVMe-oF: NVMe over Fabrics (NoF)
- NVMe/FC: NVMe over Fibre Channel (FC-NVMe, NVMe over FC)
- NVMe/RoCE: NVMe over RoCE ()
- NVMe/TCP: NVMe over TCP ()
