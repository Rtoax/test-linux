# 2007
- Google 发布 `Android` 操作系统;
# 2002
- 2002-10 RCU 添加到Linux 内核中;
# 1998
- Open Source Initiative (`OSI`) 成立，发布了开放源代码的定义和认证标准;
# 1995
- `Red Hat` 公司成立，发布了一个基于 Red Hat Linux 的商业发行版;
- 德国慕尼黑市政府成为第一个采用Linux作为主要操作系统的政府机构;
- `X/Open` introduced the UNIX 95 brand;
# 1993
- `AT&T` sold it `UNIX` System Laboratories to Novell;
- Linux 第一个商业公司 Softlanding Linux System (SLS) 成立，发布了一个基于 Slackware 的商业发行版;
- `Debian GNU/Linux` 项目开始;
- `4.4BSD` the final release from Berkeley. June 16 Novell acquires USL;
# 1992
- `Finux` (Finland Unix) 用户组成立;
- Linux 第一个发行版`Slackware` 发布，由 Patrick Volkerding 创建;
- USL releases UNIX System V Release 4.2 (Destiny, `SVR4.2`);
- October - XPG4 Brand launched by X/Open;
- December 22nd Novell announces intent to acquire USL. `Solaris 2.0` ships;
# 1991
- 1991-10-05: 林纳斯·托瓦兹在comp.os.minix新闻组上发布`linux`;
# 1989
- UNIX System V Release 4(`SVR4`) ships, unifying System V, BSD and Xenix. Installed base 1.2 million;
# 1988
- `POSIX.1` published. Open Software Foundation (OSF) and UNIX International (UI) formed. `Ultrix 4.2` ships;
# 1987
- System V Release 3(`SVR3`) including STREAMS, TLI, RFS. At this time there are 750,000 UNIX installations around the world. IRIX introduced;
# 1986
- `4.3BSD` released, including internet name server. SVID introduced. NFS shipped. AIX announced. Installed base 250,000;
# 1985
- Free Software Foundation(FSF) was founded;
- `GNU` Manifesto was published in March 1985;
# 1984
- University of California at Berkeley releases `4.2BSD`, includes `TCP/IP`, new signals and much more. X/Open formed;
- System V Release 2(`SVR2`) introduced. At this time there are 100,000 UNIX installations around the world;
# 1983
- `GNU` Project by Richard Stallman;
- Computer Research Group (CRG), UNIX System Group (USG) and a third group merge to become UNIX System Development Lab. `AT&T` announces UNIX `System V`, the first supported release. Installed base 45,000l;
- `MBR`s was publicly introduced in 1983 with PC DOS 2.0;
# 1982
- `AT&T`'s UNIX System Group (USG) release `System III`, the first public release outside Bell Laboratories. `SunOS 1.0` ships. HP-UX introduced. `Ultrix-11` Introduced;
- The original version of the `MBR` was written by David Litton of IBM in June 1982;
# 1980s
- `AT&T` released `System V`;
# 1980
- `Microsoft` introduces `Xenix`. 32V and `4BSD` introduced.
# 1975
- `UNIX` leaves home. Also widely known as Version 6, this is the first to be widely available out side of Bell Labs. The first `BSD` version (1.x) was derived from V6.
# 1973
- `Unix`(Fourth Edition) was rewritten in the C, This made it portable and changed the history of OS's.
# 1971
- Richard Stallman started his career at MIT;
# 1970
- `Unix`(First Edition) was ported to the `PDP-11`;
# 1969
- UNIX born at Bell Labs `(AT&T)`. `Ken Thompson` and `Dennis Ritchie` wrote the first version of `Unix`(The Beginning) on a `PDP-7` minicomputer;
