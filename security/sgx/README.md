SGX - Software Guard Extensions (软件防护扩展) @Intel
=====================================================

# Key Words

- enclave: 飞地


# Enable

1. BIOS SGX State/SGX Mode: **Enabled**
2. BIOS SGX Launch Control: **Enabled/Auto**
3. BIOS Secure Boot: **Disabled** (多数主板需关闭 Secure Boot 才能让 SGX 生效)
